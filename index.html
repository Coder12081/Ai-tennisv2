Automatic mode: Start tracking, then move the ball to acquire it. Static yellow tape is ignored; the camera must stay still so motion can separate the ball from court markings. The tracker holds a confirmed ball when it pauses and reacquires it if it moves quickly.

Only confirmed moving-ball detections are drawn. A confirmed track is held briefly when the ball pauses; predicted positions are never added to the measured path.

How this version works

The detector searches for saturated tennis-ball yellow, filters candidates by shape and apparent size, and follows the best candidate using motion prediction. This is classical computer vision, not a trained neural network. The match score is a heuristic, not a probability.
